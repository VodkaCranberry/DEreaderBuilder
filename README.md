# 🇩🇪 德语阅读生成器与 AI 助教 (DE-Reader Builder)

一个单文件、纯前端、由大语言模型强力驱动的德语沉浸式学习工作站。从定制阅读、划词翻译到考点特训、单词默写，再到**情景口语对练与多语言转译**，为您打造保姆级的德语学习闭环。

---

## 🌟 核心功能亮点 (Highlights)

### 1. 🎯 量身定制的千人千面阅读池 (全新收纳盒 UI)
左侧控制台采用优雅的“手风琴收纳盒”设计，功能强大且版面清爽：
- **按需主题生成**：支持 A1 到 C2 全难度覆盖。只需输入提示词（如“德国超市购物”），AI 即可生成原汁原味、难度适配的德语文章。
- **融合生词库生成**：输入你近期正在背的单词，AI 会自动编写一篇包含这些词汇的文章，并在真实语境中进行 `**高亮**` 标记强化记忆。

### 2. 🌍 任意语言智能转译德文 (NEW)
看到一篇有趣的中文/英文文章想用德语阅读？
- **自适应难度改写**：粘贴任意语言的段落，不仅支持“原文直接翻译”，更支持**强行改写为 A1-C2 任意目标难度**的德语表达（自动拆解长难句或增加高级语法）。
- **保姆级双语对照**：转换后的德语文章会自动高亮 5-8 个符合当前难度的核心词汇，并在文章最下方自动生成优美的中文对照翻译。

### 3. 🗣️ 沉浸式情景口语对练与评估 (NEW)
哑巴德语的终结者！在主视窗切换至“情景对话”面板：
- **自定义/随机场景**：输入想聊的话题（如：去面包店买面包），或留空让 AI 随机抛出实战场景。
- **逐句外教点评**：你的每一句回复，AI 都会在顺着聊下去的同时，在下方生成专属的 `💡 外教点评与优化建议`，指出语法错误并提供更地道的表达。
- **一键求助**：脑子卡壳不知道怎么回？点击“一键回答”，AI 会根据上下文为你写出一句地道的回复并附带翻译。
- **权威评估报告**：对话结束后点击“结束并报告”，AI 将脱离扮演角色，提取你本次对话的**所有发言**，生成一份包含“总体评价、易错点回顾、优化建议”的详细复盘报告。

### 4. 🧠 德语长难句与语法的“降维打击”
- **智能划词/划句翻译**：无论是在阅读还是口语对话中，遇到生词直接划选。
  - **划单词**：精确提取纯净原形，以**蓝/红/绿三色**直观标注名词词性（der/die/das），并附带双语例句。
  - **划长难句**：遇到令人头疼的框形结构或从句？划选整句，AI 会按【整体翻译】👉【结构/成分分析】👉【逐词解析】三步走彻底拆解。

### 5. 🕳️ 备考级“完形填空”与“阅读理解”特训
- **完形填空 (Lückentext)**：一键将文章中高亮的核心词汇精准挖空，右侧提供中文释义提示。输入德文后实时校验拼写与词尾变化。
- **阅读理解出题**：自动生成高度模拟歌德考试/TestDaF 的单选题/判断题，提交后自动批改，并由 AI 给出详尽的中文解析。

### 6. 🔄 完整的背单词闭环系统
- **智能原形提取**：点击查词悬浮窗底部的“加入生词本”，系统会自动剔除冠词和变位，只将纯正原形录入本地库。
- **沉浸式听写与答案提示**：在“背单词区”，你需要根据中文释义默写德语，输入框自带实时正误变色校验。实在想不起来？**点击“查看答案”一键解惑**。

### 7. 🌙 深海蓝沉稳 UI 与全局便捷侧边栏
- 全局采用极具质感的**深海蓝/蓝灰暗色调**，取代了刺眼的霓虹发光效果，色彩对比度精心调校，极大降低长时间沉浸学习的视觉疲劳。
- **全平台侧边栏随意收缩**：无论是手机端还是桌面端，随时点击左上角 `☰` 按钮即可丝滑收起侧边栏，将全部屏幕空间留给阅读与对话。

## 📖 使用指南 (User Guide)

**第一步：基础配置**
1. 在左侧边栏 【1. API 配置】 中，填入你的 DeepSeek API Key 及 Base URL。
2. 配置会自动保存在本地，下次打开无需重复输入。

**第二步：获取你的德语素材**
在左侧 【2. 阅读/对话生成】 中，展开你想使用的功能收纳盒：
- **想阅读**：展开“提示词/主题生成”或“基于单词库生成”，获取定制德文。
- **想翻译**：展开“任意语言转德语”，粘贴文本并选择目标难度，一键转换为带翻译的双语学习素材。

**第三步：沉浸式阅读与查词**
1. 在主视窗阅读文章，遇到生词鼠标划选它，即可弹出划词翻译。看完后可点击“加入生词本”。
2. 遇到看不懂的从句，直接划拉一整句，查看 AI 为你剥解的语法结构。

**第四步：情景口语特训**
1. 展开左侧“场景对话练习”收纳盒，输入话题并开启对话。
2. 切换到主界面的 **【🗣️ 情景对话】** 标签页，根据 AI 的引导输入德语。
3. 观察 AI 给出的实时语法点评，词穷时使用 **“💡 一键回答”**。
4. 聊完后点击 **“🛑 结束并报告”**，查收你的专属口语体检单。

**第五步：考点特训与词汇巩固**
1. 点击左侧 “自动出阅读题” 或 “抽取原文生成完形填空”，在主区域完成题目。
2. 切换到主视窗的 **【📝 背单词区】**，敲击键盘默写德文，拼写正确输入框将自动亮起代表通过的绿光。
